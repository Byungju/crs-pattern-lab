# 943110 — Possible Session Fixation Attack: SessionID Parameter Name with Off-Domain Referer

> **한 줄 요약**: 파라미터(인자) 이름 — 정규식 패턴 탐지 (체인 조건 2단계) [치명(CRITICAL)]

- **파일**: `REQUEST-943-APPLICATION-ATTACK-SESSION-FIXATION.conf` (line 63)
- **phase**: 2
- **검사 대상(변수)**: `ARGS_NAMES` → 파라미터(인자) 이름
- **조건(연산자)**: `@rx ^(?:json\.)?(?:j(?:se(?:ssionid|rvsession)|wsession)|(?:asp(?:\.net_)?session|zend_session_)id|p(?:hpsessi(?:on|d)|lay_session)|(?:(?:w(?:eblogic|l)|rack\.|laravel_)sessio|(?:next-auth\.session-|meteor_login_)toke)n|s(?:(?:ession[\-_]?|ails\.s)id|hiny-token)|_(?:session_id|(?:(?:flask|rails)_sessio|_(?:secure|host)-next-auth\.session-toke)n)|c(?:f(?:s?id|token)|onnect\.sid|akephp|i_session)|koa[\.:]sess)$`
- **체인 1단계**: `REQUEST_HEADERS:Referer` `@rx ^(?:ht|f)tps?://(.*?)/` → 요청 헤더 'Referer'
- **체인 2단계**: `TX:1` `!@endsWith %{request_headers.host}` → 트랜잭션 변수 '1'
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/943110.sh`](tests/943110.sh)

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `ARGS_NAMES` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `REQUEST_HEADERS:Referer` — 정규식 패턴에 매칭되면 탐지
  - 3단계: `TX:1` — 특정 문자열로 끝나면 탐지

- **무엇을 보나**: 파라미터(인자) 이름 (`ARGS_NAMES`) **및** 체인 2단계 (`REQUEST_HEADERS:Referer, TX:1`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
