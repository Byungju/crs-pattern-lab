# 943120 — Possible Session Fixation Attack: SessionID Parameter Name with No Referer

> **한 줄 요약**: 파라미터(인자) 이름 — 정규식 패턴 탐지 (체인 조건 1단계) [치명(CRITICAL)]

- **파일**: `REQUEST-943-APPLICATION-ATTACK-SESSION-FIXATION.conf` (line 96)
- **phase**: 2
- **검사 대상(변수)**: `ARGS_NAMES` → 파라미터(인자) 이름
- **조건(연산자)**: `@rx ^(?:json\.)?(?:j(?:se(?:ssionid|rvsession)|wsession)|(?:asp(?:\.net_)?session|session[\-_]?)id|phpsessi(?:on|d)|(?:weblogic|laravel_)session|_(?:session_id|flask_session)|c(?:f(?:s?id|token)|onnect\.sid))$`
- **체인 1단계**: `&REQUEST_HEADERS:Referer` `@eq 0` → 요청 헤더 'Referer' 의 개수(존재 여부)
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/943120.sh`](tests/943120.sh)

## 원본 룰

```apache
SecRule ARGS_NAMES "@rx ^(?:json\.)?(?:j(?:se(?:ssionid|rvsession)|wsession)|(?:asp(?:\.net_)?session|session[\-_]?)id|phpsessi(?:on|d)|(?:weblogic|laravel_)session|_(?:session_id|flask_session)|c(?:f(?:s?id|token)|onnect\.sid))$" \
    "id:943120,\
    phase:2,\
    block,\
    capture,\
    t:none,t:lowercase,\
    msg:'Possible Session Fixation Attack: SessionID Parameter Name with No Referer',\
    logdata:'Matched Data: %{TX.0} found within %{TX.943120_MATCHED_VAR_NAME}: %{MATCHED_VAR}',\
    tag:'application-multi',\
    tag:'language-multi',\
    tag:'platform-multi',\
    tag:'attack-fixation',\
    tag:'paranoia-level/1',\
    tag:'OWASP_CRS',\
    tag:'OWASP_CRS/ATTACK-SESSION-FIXATION',\
    tag:'capec/1000/225/21/593/61',\
    ver:'OWASP_CRS/4.30.0-dev',\
    severity:'CRITICAL',\
    setvar:'tx.943120_matched_var_name=%{matched_var_name}',\
    chain"
    SecRule &REQUEST_HEADERS:Referer "@eq 0" \
        "setvar:'tx.session_fixation_score=+%{tx.critical_anomaly_score}',\
        setvar:'tx.inbound_anomaly_score_pl1=+%{tx.critical_anomaly_score}'"
```

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `ARGS_NAMES` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `&REQUEST_HEADERS:Referer` — `eq` 조건(값 `0`)에 맞으면 탐지

- **무엇을 보나**: 파라미터(인자) 이름 (`ARGS_NAMES`) **및** 체인 1단계 (`&REQUEST_HEADERS:Referer`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: `t:lowercase` (비교 전에 적용)

- **정본**: `regex-assembly/943120.ra` (사람이 읽는 조립 파일)
- **구조**: 접두 고정 `^(?:json\.)?`, 접미 고정 `$`
- **패턴 조각 18개** (조각 중 하나라도 매칭되면 탐지):
    1. `jsessionid`
    2. `jservsession`
    3. `jwsession`
    4. `aspsessionid`
    5. `asp\.net_sessionid`
    6. `phpsession`
    7. `phpsessid`
    8. `weblogicsession`
    9. `session_id`
    10. `session-id`
    11. `sessionid`
    12. `_session_id`
    13. `cfid`
    14. `cftoken`
    15. `cfsid`
    16. `_flask_session`
    17. `connect\.sid`
    18. `laravel_session`
