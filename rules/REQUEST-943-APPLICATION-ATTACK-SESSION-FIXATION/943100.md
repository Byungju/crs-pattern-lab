# 943100 — Possible Session Fixation Attack: Setting Cookie Values in HTML

> **한 줄 요약**: 여러 입력값(파라미터·쿠키·헤더·본문 등) — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-943-APPLICATION-ATTACK-SESSION-FIXATION.conf` (line 36)
- **phase**: 2
- **검사 대상(변수)**: `REQUEST_COOKIES|REQUEST_COOKIES_NAMES|ARGS_NAMES|ARGS|XML:/*|XML://@*` → 여러 입력값(파라미터·쿠키·헤더·본문 등)
- **조건(연산자)**: `@rx (?i)\.cookie\b.*?;[^0-9A-Z_a-z]*?(?:expires|domain)[^0-9A-Z_a-z]*?=|\bhttp-equiv[^0-9A-Z_a-z]+set-cookie\b`

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: `t:urlDecodeUni` (비교 전에 적용)

- **정본**: `regex-assembly/943100.ra` (사람이 읽는 조립 파일)
- **구조**: 대소문자 무시(`(?i)`)
- **패턴 조각 5개** (조각 중 하나라도 매칭되면 탐지):
    1. `\.cookie\b.*?;\W*?`
    2. `expires`
    3. `domain`
    4. `\W*?=`
    5. `\bhttp-equiv\W+set-cookie\b`
