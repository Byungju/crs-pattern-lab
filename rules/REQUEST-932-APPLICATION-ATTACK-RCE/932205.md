# 932205 — RCE Bypass Technique

> **한 줄 요약**: 요청 헤더 'Referer' — 정규식 패턴 탐지 (체인 조건 3단계) [치명(CRITICAL)]

- **파일**: `REQUEST-932-APPLICATION-ATTACK-RCE.conf` (line 1197)
- **phase**: 1
- **검사 대상(변수)**: `REQUEST_HEADERS:Referer` → 요청 헤더 'Referer'
- **조건(연산자)**: `@rx ^[^#]+`
- **체인 1단계**: `TX:0` `@rx ^[^\.]+\.[^;\?]+[;\?](.*(['\*\?\x5c`][^\n/]+/|/[^/]+?['\*\?\x5c`]|\$[!#\$\(\*\-0-9\?-\[_a-\{]))` → 트랜잭션 변수 '0'
- **체인 2단계**: `TX:1` `@rx /` → 트랜잭션 변수 '1'
- **체인 3단계**: `TX:1` `@rx \s` → 트랜잭션 변수 '1'
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 2
- **검증**: [`tests/932205.sh`](tests/932205.sh)


## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `REQUEST_HEADERS:Referer` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `TX:0` — 정규식 패턴에 매칭되면 탐지
  - 3단계: `TX:1` — 정규식 패턴에 매칭되면 탐지
  - 4단계: `TX:1` — 정규식 패턴에 매칭되면 탐지

- **무엇을 보나**: 요청 헤더 'Referer' (`REQUEST_HEADERS:Referer`) **및** 체인 3단계 (`TX:0, TX:1, TX:1`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
