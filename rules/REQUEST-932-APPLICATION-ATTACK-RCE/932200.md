# 932200 — RCE Bypass Technique

> **한 줄 요약**: 여러 입력값(파라미터·쿠키·헤더·본문 등) — 정규식 패턴 탐지 (체인 조건 2단계) [치명(CRITICAL)]

- **파일**: `REQUEST-932-APPLICATION-ATTACK-RCE.conf` (line 1158)
- **phase**: 2
- **검사 대상(변수)**: `REQUEST_COOKIES|REQUEST_COOKIES_NAMES|ARGS_NAMES|ARGS|XML:/*|XML://@*` → 여러 입력값(파라미터·쿠키·헤더·본문 등)
- **조건(연산자)**: `@rx ['\*\?\x5c`][^\n/]+/|/[^/]+?['\*\?\x5c`]|\$[!#\$\(\*\-0-9\?-\[_a-\{]`
- **체인 1단계**: `MATCHED_VARS` `@rx /` → MATCHED_VARS
- **체인 2단계**: `MATCHED_VARS` `@rx \s` → MATCHED_VARS
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 2
- **검증**: [`tests/932200.sh`](tests/932200.sh)

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `REQUEST_COOKIES|REQUEST_COOKIES_NAMES|ARGS_NAMES|ARGS|XML:/*|XML://@*` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `MATCHED_VARS` — 정규식 패턴에 매칭되면 탐지
  - 3단계: `MATCHED_VARS` — 정규식 패턴에 매칭되면 탐지

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`REQUEST_COOKIES|REQUEST_COOKIES_NAMES|ARGS_NAMES|ARGS|XML:/*|XML://@*`) **및** 체인 2단계 (`MATCHED_VARS, MATCHED_VARS`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
