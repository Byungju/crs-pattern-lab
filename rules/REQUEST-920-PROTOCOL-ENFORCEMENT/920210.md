# 920210 — Multiple/Conflicting Connection Header Data Found

- **조건(연산자)**: `@rx \b(?:keep-alive|close),\s?(?:keep-alive|close)\b`

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 요청 헤더 'Connection' (`REQUEST_HEADERS:Connection`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 경고(WARNING) 등급으로 **점수 3** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
