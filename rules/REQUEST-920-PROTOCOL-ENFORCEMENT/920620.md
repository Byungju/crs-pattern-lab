# 920620 — Multiple Content-Type Request Headers

> **한 줄 요약**: 요청 헤더 'Content-Type' 의 개수(존재 여부) — 값 비교 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 1373)
- **phase**: 1
- **검사 대상(변수)**: `&REQUEST_HEADERS:Content-Type` → 요청 헤더 'Content-Type' 의 개수(존재 여부)
- **조건(연산자)**: `@gt 1`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 요청 헤더 'Content-Type' 의 개수(존재 여부) (`&REQUEST_HEADERS:Content-Type`)
- **어떻게 판단하나**: `gt` 조건(값 `1`)에 맞으면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 분류 / 근거 (OWASP·CWE·CAPEC)

- **공격 분류**: Protocol Abuse (요청 스머글링·프로토콜 조작 등)
- **CWE**: CWE-444 / CWE-436
- **OWASP Top 10 2025**: 직접 대응 없음 (A02/A05 맥락)
