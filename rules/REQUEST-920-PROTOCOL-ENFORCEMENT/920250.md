# 920250 — UTF8 Encoding Abuse Attack Attempt

> **한 줄 요약**: 트랜잭션 변수 'CRS_VALIDATE_UTF8_ENCODING' — 값 비교 탐지 (체인 조건 1단계) [경고(WARNING)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 414)
- **phase**: 2
- **검사 대상(변수)**: `TX:CRS_VALIDATE_UTF8_ENCODING` → 트랜잭션 변수 'CRS_VALIDATE_UTF8_ENCODING'
- **조건(연산자)**: `@eq 1`
- **체인 1단계**: `REQUEST_FILENAME|ARGS|ARGS_NAMES` `@validateUtf8Encoding` → 요청 경로(파일명) + 파라미터(인자) 값 + 파라미터(인자) 이름
- **심각도(severity)**: 경고(WARNING) → 점수 3
- **paranoia level**: 1
- **검증**: [`tests/920250.sh`](tests/920250.sh)

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `TX:CRS_VALIDATE_UTF8_ENCODING` — `eq` 조건(값 `1`)에 맞으면 탐지
  - 2단계: `REQUEST_FILENAME|ARGS|ARGS_NAMES` — UTF-8 인코딩이 비정상이면 탐지

- **무엇을 보나**: 트랜잭션 변수 'CRS_VALIDATE_UTF8_ENCODING' **및** 체인 1단계 (`REQUEST_FILENAME|ARGS|ARGS_NAMES`)
- **어떻게 판단하나**: `eq` 조건(값 `1`)에 맞으면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 경고(WARNING) 등급으로 **점수 3** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
