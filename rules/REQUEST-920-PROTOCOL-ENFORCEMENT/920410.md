# 920410 — Total uploaded files size too large

> **한 줄 요약**: 트랜잭션 변수 'COMBINED_FILE_SIZES' 의 개수(존재 여부) — 값 비교 탐지 (체인 조건 1단계) [치명(CRITICAL)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 921)
- **phase**: 2
- **검사 대상(변수)**: `&TX:COMBINED_FILE_SIZES` → 트랜잭션 변수 'COMBINED_FILE_SIZES' 의 개수(존재 여부)
- **조건(연산자)**: `@eq 1`
- **체인 1단계**: `FILES_COMBINED_SIZE` `@gt %{tx.combined_file_sizes}` → 업로드 전체 크기
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/920410.sh`](tests/920410.sh)

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `&TX:COMBINED_FILE_SIZES` — `eq` 조건(값 `1`)에 맞으면 탐지
  - 2단계: `FILES_COMBINED_SIZE` — `gt` 조건(값 `%{tx.combined_file_sizes}`)에 맞으면 탐지

- **무엇을 보나**: 트랜잭션 변수 'COMBINED_FILE_SIZES' 의 개수(존재 여부) (`&TX:COMBINED_FILE_SIZES`) **및** 체인 1단계 (`FILES_COMBINED_SIZE`)
- **어떻게 판단하나**: `eq` 조건(값 `1`)에 맞으면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
