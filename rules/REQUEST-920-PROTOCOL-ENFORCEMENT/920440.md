# 920440 — URL file extension is restricted by policy

> **한 줄 요약**: 요청 파일명 — 정규식 패턴 탐지 (체인 조건 1단계) [치명(CRITICAL)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 1127)
- **phase**: 1
- **검사 대상(변수)**: `REQUEST_BASENAME` → 요청 파일명
- **조건(연산자)**: `@rx \.([^.]+)$`
- **체인 1단계**: `TX:EXTENSION` `@within %{tx.restricted_extensions}` → 트랜잭션 변수 'EXTENSION'
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/920440.sh`](tests/920440.sh)

## 원본 룰

```apache
SecRule REQUEST_BASENAME "@rx \.([^.]+)$" \
    "id:920440,\
    phase:1,\
    block,\
    capture,\
    t:none,t:urlDecodeUni,\
    msg:'URL file extension is restricted by policy',\
    logdata:'%{TX.0}',\
    tag:'application-multi',\
    tag:'language-multi',\
    tag:'platform-multi',\
    tag:'attack-protocol',\
    tag:'paranoia-level/1',\
    tag:'OWASP_CRS',\
    tag:'OWASP_CRS/PROTOCOL-ENFORCEMENT',\
    tag:'capec/1000/210/272',\
    ver:'OWASP_CRS/4.30.0-dev',\
    severity:'CRITICAL',\
    setvar:'tx.extension=.%{tx.1}/',\
    chain"
    SecRule TX:EXTENSION "@within %{tx.restricted_extensions}" \
        "t:none,t:lowercase,\
        setvar:'tx.inbound_anomaly_score_pl1=+%{tx.critical_anomaly_score}'"
```

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `REQUEST_BASENAME` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `TX:EXTENSION` — 목록 안에 있으면 탐지

- **무엇을 보나**: 요청 파일명 (`REQUEST_BASENAME`) **및** 체인 1단계 (`TX:EXTENSION`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **CWE**: CWE-444 / CWE-436
- **OWASP Top 10 2025**: 직접 대응 없음 (A02/A05 맥락)

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: `t:urlDecodeUni` (비교 전에 적용)

- **구조**: 끝 앵커 `$`
- **문자 클래스**: `[^.]`
- 단일 패턴 — 전체 정규식은 위 **조건(연산자)** 원문 참고.
