# 920300 — Request Missing an Accept Header

> **한 줄 요약**: 요청 헤더 'Accept' 의 개수(존재 여부) — 값 비교 탐지 (체인 조건 2단계) [알림(NOTICE)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 1711)
- **phase**: 1
- **검사 대상(변수)**: `&REQUEST_HEADERS:Accept` → 요청 헤더 'Accept' 의 개수(존재 여부)
- **조건(연산자)**: `@eq 0`
- **체인 1단계**: `REQUEST_METHOD` `!@rx ^(?:OPTIONS|CONNECT)$` → HTTP 메서드
- **체인 2단계**: `REQUEST_HEADERS:User-Agent` `!@pm AppleWebKit Android` → 요청 헤더 'User-Agent'
- **심각도(severity)**: 알림(NOTICE) → 점수 2
- **paranoia level**: 3
- **검증**: [`tests/920300.sh`](tests/920300.sh)

## 원본 룰

```apache
SecRule &REQUEST_HEADERS:Accept "@eq 0" \
    "id:920300,\
    phase:1,\
    block,\
    t:none,\
    msg:'Request Missing an Accept Header',\
    tag:'application-multi',\
    tag:'language-multi',\
    tag:'platform-multi',\
    tag:'attack-protocol',\
    tag:'paranoia-level/3',\
    tag:'OWASP_CRS',\
    tag:'OWASP_CRS/PROTOCOL-ENFORCEMENT',\
    tag:'capec/1000/210/272',\
    ver:'OWASP_CRS/4.30.0-dev',\
    severity:'NOTICE',\
    chain"
    SecRule REQUEST_METHOD "!@rx ^(?:OPTIONS|CONNECT)$" \
        "chain"
        SecRule REQUEST_HEADERS:User-Agent "!@pm AppleWebKit Android" \
            "t:none,\
            setvar:'tx.inbound_anomaly_score_pl3=+%{tx.notice_anomaly_score}'"
```

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `&REQUEST_HEADERS:Accept` — `eq` 조건(값 `0`)에 맞으면 탐지
  - 2단계: `REQUEST_METHOD` — 정규식에 **매칭되지 않으면**(형식이 어긋나면) 탐지
  - 3단계: `REQUEST_HEADERS:User-Agent` — 패턴이 없으면 탐지

- **무엇을 보나**: 요청 헤더 'Accept' 의 개수(존재 여부) (`&REQUEST_HEADERS:Accept`) **및** 체인 2단계 (`REQUEST_METHOD, REQUEST_HEADERS:User-Agent`)
- **어떻게 판단하나**: `eq` 조건(값 `0`)에 맞으면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 알림(NOTICE) 등급으로 **점수 2** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **CWE**: CWE-444 / CWE-436
- **OWASP Top 10 2025**: 직접 대응 없음 (A02/A05 맥락)
- **CAPEC (CRS 태그)**: `capec/1000/210/272`

## 정규식 / 패턴 해설


### 체인 조건 — `REQUEST_METHOD` `!@rx ^(?:OPTIONS|CONNECT)$`
- **연산자 의미**: 정규식에 **매칭되지 않으면**(형식이 어긋나면) 탐지

- **구조**: 시작 앵커 `^`, 끝 앵커 `$`
- **대안(alternation) 2개** — 정규식을 `|` 기준으로 나눈 조각:
    1. `OPTIONS`
    2. `CONNECT`

### 체인 조건 — `REQUEST_HEADERS:User-Agent` `!@pm AppleWebKit Android`
- **연산자 의미**: 패턴이 없으면 탐지

- **패턴 방식**: `@pm` — 목록에 정의된 **패턴 문자열**을 대상에서 찾는다(정규식 아님).
- **패턴 목록/파일**: `AppleWebKit Android`
- `!` 가 붙어 **그 패턴이 없을 때** 탐지한다.
