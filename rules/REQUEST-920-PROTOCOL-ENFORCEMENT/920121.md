- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 1538)
- **phase**: 2
- **검사 대상(변수)**: `FILES_NAMES|FILES` → 업로드 폼 필드 이름 + 업로드 파일명(filename)
- **조건(연산자)**: `@rx ['\";=\x5c]`

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 업로드 폼 필드 이름 + 업로드 파일명(filename) (`FILES_NAMES|FILES`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **CWE**: CWE-444 / CWE-436

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
