# 920171 — GET or HEAD Request with Transfer-Encoding

> **한 줄 요약**: HTTP 메서드 — 정규식 패턴 탐지 (체인 조건 1단계) [치명(CRITICAL)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 199)
- **phase**: 1
- **검사 대상(변수)**: `REQUEST_METHOD` → HTTP 메서드
- **조건(연산자)**: `@rx ^(?:GET|HEAD)$`
- **체인 1단계**: `&REQUEST_HEADERS:Transfer-Encoding` `!@eq 0` → 요청 헤더 'Transfer-Encoding' 의 개수(존재 여부)
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/920171.sh`](tests/920171.sh)

## 원본 룰

```apache
SecRule REQUEST_METHOD "@rx ^(?:GET|HEAD)$" \
    "id:920171,\

    t:none,\
    msg:'GET or HEAD Request with Transfer-Encoding',\

    tag:'application-multi',\

    tag:'attack-protocol',\

    tag:'OWASP_CRS',\
    tag:'OWASP_CRS/PROTOCOL-ENFORCEMENT',\
    tag:'capec/1000/210/272',\
    ver:'OWASP_CRS/4.30.0-dev',\
    severity:'CRITICAL',\
    chain"
    SecRule &REQUEST_HEADERS:Transfer-Encoding "!@eq 0" \
        "t:none,\
        setvar:'tx.inbound_anomaly_score_pl1=+%{tx.critical_anomaly_score}'"
```

## 무슨 룰인가 (쉬운 설명)

**GET/HEAD 요청에 `Transfer-Encoding` 헤더가 있는 경우**를 탐지한다(`chain`). 본문이 없는 메서드에 청크 전송(TE)이 붙으면 경계 해석이 어긋나 **HTTP Request Smuggling(요청 밀수)** 에 악용될 수 있다. 근거: CWE-444, `capec/1000/210/272`. 개념: [Request Smuggling](../../modsecurity/request-smuggling.md)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `REQUEST_METHOD` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `&REQUEST_HEADERS:Transfer-Encoding` — `eq` 조건(값 `0`)에 맞지 **않으면** 탐지

- **무엇을 보나**: HTTP 메서드 (`REQUEST_METHOD`) **및** 체인 1단계 (`&REQUEST_HEADERS:Transfer-Encoding`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 분류 / 근거 (OWASP·CWE·CAPEC)

- **공격 분류**: Protocol Abuse (요청 스머글링·프로토콜 조작 등)
- **CWE**: CWE-444 / CWE-436
- **OWASP Top 10 2025**: 직접 대응 없음 (A02/A05 맥락)
- **CAPEC (CRS 태그)**: `capec/1000/210/272`
- **분류·근거 문서**: [공격 분류 개요](../../modsecurity/attack-classes.md)

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: 없음 (`t:none`)

- **구조**: 시작 앵커 `^`, 끝 앵커 `$`
- **대안(alternation) 2개** — 정규식을 `|` 기준으로 나눈 조각:
    1. `GET`
    2. `HEAD`
