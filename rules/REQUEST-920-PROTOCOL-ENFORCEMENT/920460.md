# 920460 — Abnormal character escapes in request

> **한 줄 요약**: 여러 입력값(파라미터·쿠키·헤더·본문 등) — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 1979)
- **phase**: 2
- **검사 대상(변수)**: `REQUEST_URI|REQUEST_HEADERS|ARGS|ARGS_NAMES` → 여러 입력값(파라미터·쿠키·헤더·본문 등)
- **조건(연산자)**: `@rx (?:^|[^\x5c])\x5c[cdeghijklmpqwxyz123456789]`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 4

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`REQUEST_URI|REQUEST_HEADERS|ARGS|ARGS_NAMES`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **CWE**: CWE-444 / CWE-436
- **OWASP Top 10 2025**: 직접 대응 없음 (A02/A05 맥락)
- **CAPEC (CRS 태그)**: `capec/1000/153/267`

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: `t:htmlEntityDecode`, `t:lowercase` (비교 전에 적용)

- **문자 클래스**: `[^\x5c]`, `[cdeghijklmpqwxyz123456789]`
- 단일 패턴 — 전체 정규식은 위 **조건(연산자)** 원문 참고.
