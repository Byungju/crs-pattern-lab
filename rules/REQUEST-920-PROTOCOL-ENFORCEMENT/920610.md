# 920610 — Raw (unencoded) fragment in request URI

> **한 줄 요약**: 원본 요청 URI — 문자열 포함 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 1340)
- **phase**: 1
- **검사 대상(변수)**: `REQUEST_URI_RAW` → 원본 요청 URI
- **조건(연산자)**: `@contains #`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/920610.sh`](tests/920610.sh)

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 원본 요청 URI (`REQUEST_URI_RAW`)
- **어떻게 판단하나**: 문자열을 포함하면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 분류 / 근거 (OWASP·CWE·CAPEC)

- **공격 분류**: Protocol Abuse (요청 스머글링·프로토콜 조작 등)
- **CWE**: CWE-444 / CWE-436
- **OWASP Top 10 2025**: 직접 대응 없음 (A02/A05 맥락)
