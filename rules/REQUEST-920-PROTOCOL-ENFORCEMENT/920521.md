# 920521 — Illegal Accept-Encoding header

> **한 줄 요약**: 요청 헤더 'Accept-Encoding' — 형식 검증(불일치 탐지) [치명(CRITICAL)]

- **파일**: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (line 1829)
- **phase**: 1
- **검사 대상(변수)**: `REQUEST_HEADERS:Accept-Encoding` → 요청 헤더 'Accept-Encoding'
- **조건(연산자)**: `!@rx br|compress|deflate|(?:pack200-)?gzip|identity|\*|^$|aes128gcm|exi|zstd|x-(?:compress|gzip)`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 3

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 요청 헤더 'Accept-Encoding' (`REQUEST_HEADERS:Accept-Encoding`)
- **어떻게 판단하나**: 정규식에 **매칭되지 않으면**(형식이 어긋나면) 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
