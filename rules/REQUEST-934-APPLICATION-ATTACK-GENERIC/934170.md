## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`REQUEST_FILENAME|REQUEST_COOKIES|REQUEST_COOKIES_NAMES|ARGS_NAMES|ARGS|XML:/*|XML://@*`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 분류 / 근거 (OWASP·CWE·CAPEC)

- **공격 분류**: Server-Side Request Forgery (SSRF)
- **CWE**: CWE-918
- **OWASP Top 10 2025**: A01:2025 – Broken Access Control (SSRF는 단독 항목 제외되어 포함)
- **CAPEC (CRS 태그)**: `capec/1000/152/242`
- **분류·근거 문서**: [공격 분류 개요](../../modsecurity/attack-classes.md)

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
