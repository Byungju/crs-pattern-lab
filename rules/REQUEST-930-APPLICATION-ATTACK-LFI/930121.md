## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 요청 헤더 'Referer' + 요청 헤더 'User-Agent' (`REQUEST_HEADERS:Referer|REQUEST_HEADERS:User-Agent`)
- **어떻게 판단하나**: `lfi-os-files.data` 파일의 패턴 중 하나라도 포함되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
