# 931120 — Possible Remote File Inclusion (RFI) Attack: URL Payload Used w/Trailing Question Mark Character (?)

> **한 줄 요약**: 파라미터(인자) 값 — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-931-APPLICATION-ATTACK-RFI.conf` (line 94)
- **phase**: 2
- **검사 대상(변수)**: `ARGS` → 파라미터(인자) 값
- **조건(연산자)**: `@rx ^(?i:file|ftps?|https?).*?\?+$`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/931120.sh`](tests/931120.sh)

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 파라미터(인자) 값 (`ARGS`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
