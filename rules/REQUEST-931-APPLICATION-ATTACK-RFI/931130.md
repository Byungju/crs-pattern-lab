## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `ARGS` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `TX:/rfi_parameter_.*/` — 특정 문자열로 끝나면 탐지

- **무엇을 보나**: 파라미터(인자) 값 (`ARGS`) **및** 체인 1단계 (`TX:/rfi_parameter_.*/`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: 없음 (`t:none`)
