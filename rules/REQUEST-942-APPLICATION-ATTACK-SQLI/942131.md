## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `ARGS_NAMES|ARGS|XML:/*|XML://@*` — 정규식 패턴에 매칭되면 탐지
  - 2단계: `TX:1` — 문자열과 다르면 탐지

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`ARGS_NAMES|ARGS|XML:/*|XML://@*`) **및** 체인 1단계 (`TX:1`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
