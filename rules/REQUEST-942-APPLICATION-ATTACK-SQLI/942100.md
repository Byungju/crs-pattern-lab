# 942100 — SQL Injection Attack Detected via libinjection

> **한 줄 요약**: 여러 입력값(파라미터·쿠키·헤더·본문 등) — libinjection SQLi 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-942-APPLICATION-ATTACK-SQLI.conf` (line 46)
- **phase**: 2
- **검사 대상(변수)**: `REQUEST_COOKIES|REQUEST_COOKIES_NAMES|REQUEST_HEADERS:User-Agent|REQUEST_HEADERS:Referer|ARGS_NAMES|ARGS|XML:/*|XML://@*` → 여러 입력값(파라미터·쿠키·헤더·본문 등)
- **조건(연산자)**: `@detectSQLi`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/942100.sh`](tests/942100.sh)

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`REQUEST_COOKIES|REQUEST_COOKIES_NAMES|REQUEST_HEADERS:User-Agent|REQUEST_HEADERS:Referer|ARGS_NAMES|ARGS|XML:/*|XML://@*`)
- **어떻게 판단하나**: libinjection 엔진이 **SQL 인젝션**으로 판단하면 탐지
