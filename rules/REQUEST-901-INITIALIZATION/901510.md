# 901510 — 메서드 오버라이드 파라미터 허용 기본값

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 262)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.allow_method_override_parameter=0`
- **로그**: 없음(nolog)
- **검증**: [`tests/901510.sh`](tests/901510.sh)

## 조건

```
SecRule &TX:allow_method_override_parameter "@eq 0"
```

## 동작

`tx.allow_method_override_parameter` 를 **0**(허용 안 함)으로 설정한다.

## 설명 / 영향

- Laravel/Rails/Symfony 등이 지원하는 `_method` 파라미터(쿼리/본문으로 PUT/PATCH/DELETE 위장)의
  허용 여부를 제어한다.
- 사용처: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` 의 `920450` 부근에서
  `TX:allow_method_override_parameter @eq 0` 일 때 `_method` 사용(PL2+)을 차단한다.
- 기본 0 인 이유: WAF 우회(POST + `_method=DELETE`), CSRF(SameSite=Lax 우회),
  메서드 기반 ACL 우회에 악용될 수 있다.
- `X-HTTP-Method-Override` 헤더는 별도 룰 `920450` 이 처리한다.
