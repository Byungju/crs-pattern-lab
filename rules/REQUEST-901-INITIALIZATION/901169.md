# 901169 — UTF-8 검증 활성화 기본값

> **한 줄 요약**: UTF-8 검증 활성화 기본값(1)을 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 282)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.crs_validate_utf8_encoding=1`
- **로그**: 없음(nolog)
- **검증**: [`tests/901169.sh`](tests/901169.sh)

## 조건

```
SecRule &TX:crs_validate_utf8_encoding "@eq 0"
```

## 동작

`tx.crs_validate_utf8_encoding` 를 **1**(검사 활성)로 설정한다.

## 관련 룰 / 흐름 (쉬운 설명)

- `REQUEST_FILENAME`, `ARGS`, `ARGS_NAMES` 의 **잘못된 UTF-8 인코딩**을 탐지한다.
- 사용처: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf`.
- non-UTF-8 파라미터를 쓰는 사이트에서는 FP 가 날 수 있다.
  비활성화하려면 `crs-setup.conf` 의 `900950` 을 주석 해제(=0 설정)한다.
- UTF-8 만 검사하며 UTF-16 등은 검증하지 않는다.
