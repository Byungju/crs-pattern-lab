## 조건

```
SecRule UNIQUE_ID "@rx ^[a-f]*([0-9])[a-f]*([0-9])"
```

`UNIQUE_ID` 의 sha1(hex) 문자열에서 처음 등장하는 정수 2개를 capture 한다.

## 동작

`TX.sampling_rnd100` 에 두 자리 의사난수(00~99)를 설정한다.

## 설명 / 영향

- `901450` 이 이 난수와 `sampling_percentage` 를 비교해 요청을 CRS 검사 대상에서 제외할지 결정한다.
- 암호학적으로 안전한 난수가 아니라, 샘플링용 저비용 난수다.
- `sampling_percentage=100` 이면 `901400` 이 블록을 skip 하므로 실행되지 않는다.
