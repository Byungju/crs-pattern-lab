# 901171 — 금지 요청 헤더(extended) 기본값

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 243)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.restricted_headers_extended=/accept-charset/`
- **로그**: 없음(nolog)
- **검증**: [`tests/901171.sh`](tests/901171.sh)

## 조건

```
SecRule &TX:restricted_headers_extended "@eq 0"
```

## 동작

**상위 PL 에서 금지**하는 요청 헤더 목록을 `/헤더명/` 형식으로 설정한다. 기본값은 `/accept-charset/`.

## 설명 / 영향

- basic 목록과 달리 FP 가능성이 있어 상위 paranoia level 에서만 차단한다.
- `/accept-charset/` 는 폐기된 헤더로, WAF 가 디코딩하지 못하는 charset 을 요청해
  응답 우회를 시도하는 지표가 될 수 있다.
- 사용처: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf`.
