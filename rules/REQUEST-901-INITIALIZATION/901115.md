# 901115 — Early Blocking 기본값

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 106)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.early_blocking=0`
- **로그**: 없음(nolog)
- **검증**: [`tests/901115.sh`](tests/901115.sh)

## 조건

```
SecRule &TX:early_blocking "@eq 0"
```

## 동작

`tx.early_blocking` 를 **0**(비활성)으로 설정한다.

## 설명 / 영향

- 기본은 0 이며, 1 로 설정하면 phase 1 종료 시점에 인바운드 점수를 먼저 평가해
  임계값을 넘으면 **즉시 차단**하고 phase 2 평가를 생략한다.
- 사용처: `REQUEST-949-BLOCKING-EVALUATION.conf`, `RESPONSE-959-BLOCKING-EVALUATION.conf`.
- 주의: 조기 차단 시 phase 2 에서 드러났을 추가 정보(alert)가 로그에 남지 않는다.
