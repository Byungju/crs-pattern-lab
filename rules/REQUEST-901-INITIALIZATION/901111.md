# 901111 — 어노말리 점수 보고(reporting) 레벨 기본값

> **한 줄 요약**: 점수 보고(reporting) 레벨 기본값(4)을 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 96)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.reporting_level=4`
- **로그**: 없음(nolog)
- **검증**: [`tests/901111.sh`](tests/901111.sh)

## 조건

```
SecRule &TX:reporting_level "@eq 0"
```

## 동작

`tx.reporting_level` 를 **4** 로 설정한다.

## 관련 룰 / 흐름 (쉬운 설명)

- phase 5 의 상세 보고 룰(`RESPONSE-980-CORRELATION.conf`)의 상세 수준을 제어한다.
  - 0=비활성, 1=차단 점수 임계값, 2=탐지 점수 임계값, 3=차단 점수>0, 4=탐지 점수>0, 5=모든 요청
- 레벨 4 는 "탐지 점수가 0보다 큰 요청"까지 보고한다. 차단되지 않았지만 상위 PL 에서
  걸릴 수 있었던 요청을 파악하는 FP 튜닝에 유용하다.
- Nginx 처럼 access log 커스터마이즈가 어려운 환경에서는 레벨 5가 유용하다.

## 검증

```
./tests/901111.sh
PASS 룰 901111: reporting 초기화 (reporting=4)
```
