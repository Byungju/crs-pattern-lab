# 901163 — 허용 HTTP 버전 기본값

> **한 줄 요약**: 허용 HTTP 버전 목록 기본값을 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 213)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.allowed_http_versions=HTTP/1.0 HTTP/1.1 HTTP/2 HTTP/2.0 HTTP/3 HTTP/3.0`
- **로그**: 없음(nolog)
- **검증**: [`tests/901163.sh`](tests/901163.sh)

## 조건

```
SecRule &TX:allowed_http_versions "@eq 0"
```

## 동작

허용 HTTP 버전 목록을 설정한다.

## 관련 룰 / 흐름 (쉬운 설명)

- 웹서버에 따라 `HTTP/2` 와 `HTTP/2.0` 표기가 달라 둘 다 포함한다.
- 사용처: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` (`920100` 은 비정상 요청 라인 처리).
- `HTTP/0.9` 는 RFC 9110 에서 폐기되었고 목록에 없다.
- `HTTP/0.9` 처럼 프로토콜 접미사가 없는 요청 라인은 이 설정과 무관하게 `920100` 이 차단한다.
