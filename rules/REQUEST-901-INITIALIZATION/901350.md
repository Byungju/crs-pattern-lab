# 901350 — body processor URLENCODED 강제

> **한 줄 요약**: body processor 를 URLENCODED 로 강제한다(기본 비활성).

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 387)
- **phase**: 1
- **action**: `pass`, `nolog`, `noauditlog`, chain → `ctl:requestBodyProcessor=URLENCODED`
- **로그**: 없음 (nolog + noauditlog)
- **검증**: [`tests/901350.sh`](tests/901350.sh) — **기본 SKIP**

## 조건

```
SecRule TX:enforce_bodyproc_urlencoded "@eq 1" ... chain
    SecRule REQBODY_PROCESSOR "!@rx (?:URLENCODED|MULTIPART|XML|JSON)" "ctl:requestBodyProcessor=URLENCODED"
```

`tx.enforce_bodyproc_urlencoded=1`(crs-setup `900010`)이고, body processor 가 미지원일 때만 동작한다.

## 동작

요청 본문을 URLENCODED 로 강제 파싱하여 `ARGS_POST` 등으로 검사 가능하게 한다.

## 관련 룰 / 흐름 (쉬운 설명)

- Content-Type 미설정/미지원 요청의 검사 우회를 막는 강력한 옵션이다.
- 엔진 전역 동작을 바꾸고 PL1 에서도 FP 를 유발할 수 있어 기본 비활성(0)이다.
- 기본 설정에서는 901350 이 실행되지 않는다.

## 검증 (SKIP)

```
./tests/901350.sh
SKIP 901350: body processor 강제는 tx.enforce_bodyproc_urlencoded=0 이라 기본 비활성(900010 활성화 필요)
```

활성화 검증: `crs-setup.conf` 의 `900010` 주석 해제(=1) 후 디버그 로그에서 `requestBodyProcessor=URLENCODED` 확인.
