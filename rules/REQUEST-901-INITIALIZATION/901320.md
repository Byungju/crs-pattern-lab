# 901320 — 기본 컬렉션(GLOBAL/IP) 초기화

> **한 줄 요약**: GLOBAL/IP 컬렉션을 초기화한다(기본 비활성).

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 352)
- **phase**: 1
- **action**: `pass`, `nolog`, `initcol:global=global`, `initcol:ip=...` (chain)
- **로그**: 없음(nolog)
- **검증**: [`tests/901320.sh`](tests/901320.sh) — **기본 SKIP**

## 조건

```
SecRule &TX:ENABLE_DEFAULT_COLLECTIONS "@eq 1" ... chain
    SecRule TX:ENABLE_DEFAULT_COLLECTIONS "@eq 1" chain
        SecRule TX:ua_hash "@unconditionalMatch" "... initcol:global=global, initcol:ip=%{remote_addr}_%{MATCHED_VAR}"
```

`tx.enable_default_collections=1`(crs-setup `900130`)일 때만 동작한다.

## 동작

- GLOBAL 컬렉션과 IP 컬렉션을 생성/초기화한다.
- IP 컬렉션 키는 `remote_addr` + `sha1(hexEncode(User-Agent))` 조합이다.

## 관련 룰 / 흐름 (쉬운 설명)

- 코어 룰은 사용하지 않으며, **플러그인**(예: DoS protection)이 두 컬렉션을 가정할 때 필요하다.
- 기본 비활성(`tx.enable_default_collections` 미설정 → 0)이라 실제로는 초기화되지 않는다.
- `SecDataDir` 에 영구 저장되며 `SecCollectionTimeout` 이 만료를 제어한다.

## 검증 (SKIP)

기본 설정에서 `ENABLE_DEFAULT_COLLECTIONS` 가 0 이라 실행되지 않는다.

```
./tests/901320.sh
SKIP 901320: ENABLE_DEFAULT_COLLECTIONS 컬렉션 초기화는 기본 비활성(tx.enable_default_collections=0)
```

활성화 검증: `crs-setup.conf` 의 `900130` 을 주석 해제(=1)한 뒤, debug 로그에서 `initcol` 실행 확인.

## 참고

- CRS 는 IP/GLOBAL 컬렉션 생성을 테스트하지 않는다고 명시(ftw 한계).
