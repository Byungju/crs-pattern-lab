# 901100 — 인바운드 어노말리 임계값 기본값

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 76)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.inbound_anomaly_score_threshold=5`
- **로그**: 없음(nolog)
- **검증**: [`tests/901100.sh`](tests/901100.sh)

## 조건

```
SecRule &TX:inbound_anomaly_score_threshold "@eq 0"
```

`crs-setup.conf` 의 `900110` 에서 설정되지 않았을 때만 기본값을 채운다.

## 동작

`tx.inbound_anomaly_score_threshold` 를 **5** 로 설정한다.

## 설명 / 영향

- 인바운드(요청) 누적 어노말리 점수가 이 값 이상이면 차단된다.
- 사용처: `REQUEST-949-BLOCKING-EVALUATION.conf` (차단 판정), `RESPONSE-980-CORRELATION.conf`.
- critical severity 룰(점수 5) 1개만 매칭돼도 기본 임계값에서는 차단된다.
- 값을 올리면 덜 민감해지지만 LFI/RFI/RCE/데이터유출 보호가 약화된다.
