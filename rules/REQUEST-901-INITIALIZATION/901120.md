# 901120 — 차단 Paranoia Level 기본값

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 116)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.blocking_paranoia_level=1`
- **로그**: 없음(nolog)
- **검증**: [`tests/901120.sh`](tests/901120.sh)

## 조건

```
SecRule &TX:blocking_paranoia_level "@eq 0"
```

## 동작

`tx.blocking_paranoia_level` 를 **1** 로 설정한다.

## 설명 / 영향

- **차단 점수에 반영할 최대 PL**. 이 값 이하 PL 의 룰 매칭만 `blocking_inbound_anomaly_score`
  에 합산된다.
- 사용처: `REQUEST-949-BLOCKING-EVALUATION.conf` 의 `949052`(`@ge 1`), `949053`(`@ge 2`) 등이
  `TX:BLOCKING_PARANOIA_LEVEL` 을 검사해 PL별 점수를 blocking 스코어에 더한다.
- `tx.detection_paranoia_level` 이 이 값보다 크면, 상위 PL 룰은 **평가만** 되고 차단 점수에는
  반영되지 않는다(점진적 PL 상향 전략).
