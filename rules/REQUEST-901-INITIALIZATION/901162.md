# 901162 — 허용 요청 Content-Type 기본값

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 193)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.allowed_request_content_type=|application/x-www-form-urlencoded| |multipart/form-data| |text/xml| |application/xml| |application/soap+xml| |application/json|`
- **로그**: 없음(nolog)
- **검증**: [`tests/901162.sh`](tests/901162.sh)

## 조건

```
SecRule &TX:allowed_request_content_type "@eq 0"
```

## 동작

허용 Content-Type 목록을 설정한다. 각 항목은 `|...|` 로 감싼다.

## 설명 / 영향

- 사용처: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf` 의 `920420`(`@within` 연산자).
  - `@within` 은 **대소문자 구분**이므로 목록은 소문자로 유지한다.
- 우회 주의: body processor 를 활성화하지 않는 Content-Type(`text/plain` 등)을 허용하면,
  백엔드는 JSON/XML 로 해석하지만 WAF 는 파싱하지 않아 우회될 수 있다.
  허용 시 반드시 대응 body parser(예: modsecurity.conf 의 `200001`/`200006`)를 함께 켠다.
