# 901165 — 금지 요청 헤더(basic) 기본값

> **한 줄 요약**: 항상 금지하는 요청 헤더(basic) 목록 기본값을 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 233)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.restricted_headers_basic=/content-encoding/ /proxy/ ... /expect/`
- **로그**: 없음(nolog)
- **검증**: [`tests/901165.sh`](tests/901165.sh)

## 조건

```
SecRule &TX:restricted_headers_basic "@eq 0"
```

## 동작

**항상 금지**하는 요청 헤더 목록을 `/헤더명/`(소문자) 형식으로 설정한다.

기본 목록: `content-encoding, proxy, lock-token, content-range, if, x-http-method-override,
x-http-method, x-method-override, x-middleware-subrequest, expect`

## 관련 룰 / 흐름 (쉬운 설명)

- 사용처: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf`.
- 각 헤더의 차단 사유:
  - `/proxy/` — `httpoxy` 취약점 방지
  - `/x-http-method-override/`, `/x-http-method/`, `/x-method-override/` — 메서드 오버라이드 공격 방지
  - `/x-middleware-subrequest/` — CVE-2025-29927 (Next.js)
  - `/expect/` — Expect 기반 desync 공격 방지
  - `/content-encoding/` — 압축 본문 우회 방지(WAF 가 압축 본문을 검사하지 못함)
