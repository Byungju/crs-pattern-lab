# 901168 — 허용 Content-Type charset 기본값

> **한 줄 요약**: 허용 charset 목록 기본값을 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 203)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.allowed_request_content_type_charset=|utf-8| |iso-8859-1| |iso-8859-15| |windows-1252|`
- **로그**: 없음(nolog)
- **검증**: [`tests/901168.sh`](tests/901168.sh)

## 조건

```
SecRule &TX:allowed_request_content_type_charset "@eq 0"
```

## 동작

허용 charset 목록을 `|...|` 형식으로 설정한다.

## 관련 룰 / 흐름 (쉬운 설명)

- 사용처: `REQUEST-920-PROTOCOL-ENFORCEMENT.conf`, `REQUEST-922-MULTIPART-ATTACK.conf`.
- charset 추가 시 `regex-assembly/include/allowed-charsets.ra` 수정 및 정규식 재생성이 필요하다.
- 경고: WAF 가 디코딩하지 못하는 charset 을 허용하면 body 전체 우회가 가능하므로 신중히 추가한다.
