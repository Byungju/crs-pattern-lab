# 901130 — 샘플링 비율 기본값

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 136)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.sampling_percentage=100`
- **로그**: 없음(nolog)
- **검증**: [`tests/901130.sh`](tests/901130.sh)

## 조건

```
SecRule &TX:sampling_percentage "@eq 0"
```

## 동작

`tx.sampling_percentage` 를 **100**(모든 요청 검사)으로 설정한다.

## 설명 / 영향

- CRS 를 검사할 요청 비율(%). 의사난수(`TX.sampling_rnd100`)와 비교해 일부 요청을 우회시킨다.
- 사용처: 이 파일의 `901400`(100이면 skip), `901450`(난수 < 비율이면 CRS 비활성).
- 100 미만이면 일부 요청은 CRS 검사를 **완전히 우회**하므로 보호 공백이 생긴다.
