# 901170 — 응답 분석 건너뛰기 기본값

> **한 줄 요약**: 응답 분석 건너뛰기 기본값(0)을 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 292)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.crs_skip_response_analysis=0`
- **로그**: 없음(nolog)
- **검증**: [`tests/901170.sh`](tests/901170.sh)

## 조건

```
SecRule &TX:crs_skip_response_analysis "@eq 0"
```

## 동작

`tx.crs_skip_response_analysis` 를 **0**(응답 검사 수행)으로 설정한다.

## 관련 룰 / 흐름 (쉬운 설명)

- 사용처: `RESPONSE-950-DATA-LEAKAGES.conf` 의 `950010` 이 `@eq 1` 일 때
  `ctl:ruleRemoveByTag=OWASP_CRS` 등으로 응답 룰 전체를 skip 한다.
- 응답 검사는 `SecResponseBodyAccess On` 이 전제이며, 큰 응답을 검사하므로
  RFDoS(Response Filter DoS) 공격 표면이 된다.
- 응답 검사를 끄려면 `crs-setup.conf` 의 `900500` 을 주석 해제(=1)한다.

## 검증

```
./tests/901170.sh
PASS 룰 901170: skip_resp 초기화 (skip_resp=0)
```

## 참고

- 설정값 변경: `crs-setup.conf` 의 `900500`.
