# 901400 — 샘플링 블록 건너뛰기

> **한 줄 요약**: 샘플링 100% 이면 샘플링 블록을 건너뛴다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 430)
- **phase**: 1
- **action**: `pass`, `nolog`, `skipAfter:END-SAMPLING`
- **로그**: 없음(nolog)
- **검증**: [`tests/901400.sh`](tests/901400.sh)

## 조건

```
SecRule TX:sampling_percentage "@eq 100"
```

## 동작

`sampling_percentage` 가 100 이면 `skipAfter:END-SAMPLING` 으로
샘플링 관련 룰(901410, 901450)을 **건너뛴다**.

## 관련 룰 / 흐름 (쉬운 설명)

- 100%(전수 검사)일 때는 난수 계산/우회 판단이 불필요하므로 성능을 위해 블록을 skip 한다.
- `END-SAMPLING` 은 파일 끝의 `SecMarker "END-SAMPLING"` 을 가리킨다.
- `sampling_percentage` 가 100 미만일 때만 901410/901450 이 실행된다.

## 검증

기본값 100 에서 901410 이 실행되지 않아 `tx.sampling_rnd100` 이 비어 있음을 확인한다.

```
./tests/901400.sh
PASS 901400: 샘플링 난수(901410) 미계산(블록 skip) (sampling_rnd100=)
```
