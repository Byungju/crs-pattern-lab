# 901160 — 허용 HTTP 메서드 기본값

> **한 줄 요약**: 허용 HTTP 메서드 목록 기본값(GET HEAD POST OPTIONS)을 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 183)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.allowed_methods=GET HEAD POST OPTIONS`
- **로그**: 없음(nolog)
- **검증**: [`tests/901160.sh`](tests/901160.sh)

## 조건

```
SecRule &TX:allowed_methods "@eq 0"
```

## 동작

`tx.allowed_methods` 를 **`GET HEAD POST OPTIONS`** 로 설정한다.

## 관련 룰 / 흐름 (쉬운 설명)

- 정책상 허용하는 HTTP 메서드 목록(공백 구분, 대문자).
- 사용처: `REQUEST-911-METHOD-ENFORCEMENT.conf` 가 이 목록 밖의 메서드를 차단한다.
- 기본에서 PUT/DELETE/PATCH 등은 허용되지 않는다.
  - PUT 은 서버에 임의 데이터를 저장시킬 수 있어 기본 비활성.
  - REST API: `PUT PATCH DELETE` 추가, WebDAV: `CHECKOUT COPY ...` 등 추가.
