# 901500 — Paranoia Level 설정 정합성 검사

> **한 줄 요약**: PL 설정이 잘못됐으면(탐지 PL < 차단 PL) 500 으로 막는 설정 오류 안전장치.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 482)
- **phase**: 1
- **action**: `deny`, `status:500`, `t:none`, `log`
- **로그**: error log
- **검증**: [`tests/901500.sh`](tests/901500.sh)

## 조건

```
SecRule TX:detection_paranoia_level "@lt %{tx.blocking_paranoia_level}"
```

탐지 PL 이 차단 PL **보다 낮으면** 매칭 (허용되지 않는 설정).

## 동작

`deny,status:500` 으로 요청을 차단하고
"Detection paranoia level configured is lower than the paranoia level itself. This is illegal." 을 남긴다.

## 관련 룰 / 흐름 (쉬운 설명)

- `tx.detection_paranoia_level` 은 `tx.blocking_paranoia_level` 이상이어야 한다.
  (탐지 범위가 차단 범위를 포함해야 논리적으로 일관)
- 위반 시 `crs-setup.conf` 의 `900000`/`900001` 설정 오류로 보고 즉시 중단한다.
- 정상 설정에서는 매칭되지 않는 **설정 검증 안전장치** 룰이다.

## 검증

`blocking_paranoia_level=2`, `detection_paranoia_level=1` 로 강제한 별도 인스턴스로 확인.

```
./tests/901500.sh
PASS 901500: PL 설정 오류 감지 차단 (HTTP 500)
LOG  Access denied with code 500 (phase 1) ... [id "901500"] ...
```
