# 901125 — 탐지 Paranoia Level 기본값

> **한 줄 요약**: 탐지 paranoia level 기본값을 차단 PL과 같게 채운다.

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 126)
- **phase**: 1
- **action**: `pass`, `nolog`, `setvar:tx.detection_paranoia_level=%{TX.blocking_paranoia_level}`
- **로그**: 없음(nolog)
- **검증**: [`tests/901125.sh`](tests/901125.sh)

## 조건

```
SecRule &TX:detection_paranoia_level "@eq 0"
```

## 동작

`tx.detection_paranoia_level` 을 **`tx.blocking_paranoia_level` 값으로** 설정한다(기본 1).

## 관련 룰 / 흐름 (쉬운 설명)

- **실행할 최대 PL**. 대부분의 CRS 룰이 `TX:detection_paranoia_level` 을 검사해
  해당 PL 이하일 때 실행된다(예: `REQUEST-942-...conf` 의 PL2/3/4 섹션).
- 기본은 blocking PL 과 동일하므로 "탐지=차단" 범위가 같다.
- detection > blocking 으로 두면 상위 PL 룰은 실행되어(`detection_*_anomaly_score` 누적)
  로그에 보이지만, 차단에는 반영되지 않아 FP 위험 없이 관찰할 수 있다.
- 성능: detection PL 을 올리면 blocking PL 을 올린 것과 동일한 비용이 든다.
