# 901450 — 샘플링 제외 결정

- **파일**: `REQUEST-901-INITIALIZATION.conf` (line 463)
- **phase**: 1
- **action**: `pass`, `log`, `noauditlog`, `ctl:ruleRemoveByTag=OWASP_CRS`
- **로그**: error log (log, noauditlog)
- **검증**: [`tests/901450.sh`](tests/901450.sh) — **기본 SKIP**

## 조건

```
SecRule TX:sampling_rnd100 "!@lt %{tx.sampling_percentage}"
crs-linter:ignore:pass_nolog
```

난수(0~99)가 `sampling_percentage` 보다 작지 않으면(=검사 대상에서 제외) 매칭.

## 동작

`ctl:ruleRemoveByTag=OWASP_CRS` 로 이 트랜잭션의 **CRS 룰 전체를 비활성화**하고,
error log 에 "Sampling: Disable the rule engine ..." 메시지를 남긴다.

## 설명 / 영향

- 신규 도입 시 일부 요청만 검사해 영향을 줄이는 "Easing In" 전략의 핵심이다.
- 제외된 요청은 감사 로그가 남지 않아 로그가 가볍다(필요 시 `SecRuleUpdateActionById 901450 "nolog"`).
- `sampling_percentage=100` 이면 `901400` 이 블록을 skip 하므로 실행되지 않는다.

## 검증 (SKIP)

```
./tests/901450.sh
SKIP 901450: sampling=100 이면 샘플링 제외 룰이 실행되지 않음(샘플링 활성화 시 검증)
```

활성화 검증: `crs-setup.conf` 의 `900400`(`tx.sampling_percentage`)을 낮춘 뒤
error log 의 샘플링 메시지와 `ruleRemoveByTag` 효과를 확인.
