# 921180 — HTTP Parameter Pollution (%{MATCHED_VAR_NAME})

> **한 줄 요약**: 트랜잭션 변수 '/paramcounter_.*/' — 값 비교 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-921-PROTOCOL-ATTACK.conf` (line 509)
- **phase**: 2
- **검사 대상(변수)**: `TX:/paramcounter_.*/` → 트랜잭션 변수 '/paramcounter_.*/'
- **조건(연산자)**: `@gt 1`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 3
- **검증**: [`tests/921180.sh`](tests/921180.sh)

## 원본 룰

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 트랜잭션 변수 '/paramcounter_.*/'
- **어떻게 판단하나**: `gt` 조건(값 `1`)에 맞으면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
