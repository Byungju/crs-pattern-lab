# 921120 — HTTP Response Splitting Attack

> **한 줄 요약**: 여러 입력값(파라미터·쿠키·헤더·본문 등) — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-921-PROTOCOL-ATTACK.conf` (line 77)
- **phase**: 2
- **검사 대상(변수)**: `REQUEST_COOKIES|REQUEST_COOKIES_NAMES|ARGS_NAMES|ARGS|XML:/*|XML://@*` → 여러 입력값(파라미터·쿠키·헤더·본문 등)
- **조건(연산자)**: `@rx [\n\r][^0-9A-Z_a-z]*?(?:content-(?:type|length)|set-cookie|location):[\s\x0b]*[0-9A-Z_a-z]`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/921120.sh`](tests/921120.sh)

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`REQUEST_COOKIES|REQUEST_COOKIES_NAMES|ARGS_NAMES|ARGS|XML:/*|XML://@*`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 분류 / 근거 (OWASP·CWE·CAPEC)

- **공격 분류**: Protocol Abuse (요청 스머글링·프로토콜 조작 등)
- **CWE**: CWE-444 / CWE-436
- **OWASP Top 10 2025**: 직접 대응 없음 (A02/A05 맥락)
- **CAPEC (CRS 태그)**: `capec/1000/210/272/220/34`
- **분류·근거 문서**: [공격 분류 개요](../../modsecurity/attack-classes.md)

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: `t:lowercase` (비교 전에 적용)

- **정본**: `regex-assembly/921120.ra` (사람이 읽는 조립 파일)
- **패턴 조각 6개** (조각 중 하나라도 매칭되면 탐지):
    1. `content-type`
    2. `content-length`
    3. `set-cookie`
    4. `location`
    5. `[\r\n]\W*?`
    6. `:\s*\w`
