# 921220 — HTTP Parameter Pollution possible via array notation

> **한 줄 요약**: 파라미터(인자) 이름 — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-921-PROTOCOL-ATTACK.conf` (line 602)
- **phase**: 2
- **검사 대상(변수)**: `ARGS_NAMES` → 파라미터(인자) 이름
- **조건(연산자)**: `@rx \[`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 4
- **검증**: [`tests/921220.sh`](tests/921220.sh)

## 원본 룰

```apache
SecRule ARGS_NAMES "@rx \[" \
    "id:921220,\
    phase:2,\

    capture,\
    log,\

    setvar:'tx.http_violation_score=+%{tx.critical_anomaly_score}',\
    setvar:'tx.inbound_anomaly_score_pl4=+%{tx.critical_anomaly_score}'"
```

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 파라미터(인자) 이름 (`ARGS_NAMES`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
