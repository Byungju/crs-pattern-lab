# 921160 — HTTP Header Injection Attack via payload (CR/LF and header-name detected)

> **한 줄 요약**: GET 파라미터 이름 + GET 파라미터 값 — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-921-PROTOCOL-ATTACK.conf` (line 190)
- **phase**: 1
- **검사 대상(변수)**: `ARGS_GET_NAMES|ARGS_GET` → GET 파라미터 이름 + GET 파라미터 값
- **조건(연산자)**: `@rx [\n\r]+(?:[\s\x0b]|location|re(?:fresh|mote-(?:ip|addr))|(?:set-)?cookie|forwarded-(?:(?:fo|serve)r|host)|host|via|originating-IP|x-(?:forwarded-(?:(?:fo|serve)r|host)|host|via|remote-(?:ip|addr)|originating-IP))[\s\x0b]*:`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/921160.sh`](tests/921160.sh)

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: GET 파라미터 이름 + GET 파라미터 값 (`ARGS_GET_NAMES|ARGS_GET`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
