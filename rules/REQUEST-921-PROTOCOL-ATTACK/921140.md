# 921140 — HTTP Header Injection Attack via headers

> **한 줄 요약**: 요청 헤더 + 요청 헤더 — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-921-PROTOCOL-ATTACK.conf` (line 134)
- **phase**: 1
- **검사 대상(변수)**: `REQUEST_HEADERS_NAMES|REQUEST_HEADERS` → 요청 헤더 + 요청 헤더
- **조건(연산자)**: `@rx [\n\r]`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 요청 헤더 + 요청 헤더 (`REQUEST_HEADERS_NAMES|REQUEST_HEADERS`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
