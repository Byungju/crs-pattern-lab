# 922100 — Multipart content type global _charset_ definition is not allowed by policy

> **한 줄 요약**: multipart 파트 헤더 의 개수(존재 여부) — 값 비교 탐지 (체인 조건 1단계) [치명(CRITICAL)]

- **파일**: `REQUEST-922-MULTIPART-ATTACK.conf` (line 27)
- **phase**: 2
- **검사 대상(변수)**: `&MULTIPART_PART_HEADERS:_charset_` → multipart 파트 헤더 의 개수(존재 여부)
- **조건(연산자)**: `!@eq 0`
- **체인 1단계**: `TX:922100_CHARSET` `!@within %{tx.allowed_request_content_type_charset}` → 트랜잭션 변수 '922100_CHARSET'
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/922100.sh`](tests/922100.sh)

## 원본 룰

```apache
SecRule &MULTIPART_PART_HEADERS:_charset_ "!@eq 0" \
    "id:922100,\
    phase:2,\
    block,\
    t:none,\
    msg:'Multipart content type global _charset_ definition is not allowed by policy',\
    logdata:'Matched Data: %{ARGS._charset_}',\
    tag:'application-multi',\
    tag:'language-multi',\
    tag:'platform-multi',\
    tag:'attack-multipart-header',\
    tag:'paranoia-level/1',\
    tag:'OWASP_CRS',\
    tag:'OWASP_CRS/MULTIPART-ATTACK',\
    tag:'capec/1000/255/153',\
    ver:'OWASP_CRS/4.30.0-dev',\
    severity:'CRITICAL',\
    setvar:'tx.922100_charset=|%{ARGS._charset_}|',\
    chain"
    SecRule TX:922100_CHARSET "!@within %{tx.allowed_request_content_type_charset}" \
        "t:lowercase,\
        setvar:'tx.inbound_anomaly_score_pl1=+%{tx.critical_anomaly_score}'"
```

## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `&MULTIPART_PART_HEADERS:_charset_` — `eq` 조건(값 `0`)에 맞지 **않으면** 탐지
  - 2단계: `TX:922100_CHARSET` — 목록에 **없으면** 탐지

- **무엇을 보나**: multipart 파트 헤더 의 개수(존재 여부) (`&MULTIPART_PART_HEADERS:_charset_`) **및** 체인 1단계 (`TX:922100_CHARSET`)
- **어떻게 판단하나**: `eq` 조건(값 `0`)에 맞지 **않으면** 탐지 (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
