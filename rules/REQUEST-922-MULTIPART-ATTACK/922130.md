# 922130 — Multipart header contains characters outside of valid range

> **한 줄 요약**: multipart 파트 헤더 — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-922-MULTIPART-ATTACK.conf` (line 139)
- **phase**: 2
- **검사 대상(변수)**: `MULTIPART_PART_HEADERS` → multipart 파트 헤더
- **조건(연산자)**: `@rx [^\x21-\x7E][\x21-\x39\x3B-\x7E]*:`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/922130.sh`](tests/922130.sh)

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: multipart 파트 헤더 (`MULTIPART_PART_HEADERS`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **CWE**: CWE-436

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
