## 무슨 룰인가 (쉬운 설명)

- **`chain` 룰**: 아래 단계가 **모두 참일 때만** 매칭된다(AND).
  - 1단계: `` — 조건 없음
  - 2단계: `MATCHED_VARS` — 정규식 패턴에 매칭되면 탐지

- **무엇을 보나**: 조건 **및** 체인 1단계 (`MATCHED_VARS`)
- **어떻게 판단하나**: 항상 실행(조건 없음) (모든 체인 단계가 참일 때)
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).
- 조건이 없는 **초기화/설정 액션** 룰이다(`SecAction`).
