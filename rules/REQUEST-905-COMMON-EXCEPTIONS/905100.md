# 905100 — Apache SSL pinger 예외 (실환경 미발동)

> **한 줄 요약**: 조건(`REQUEST_LINE`이 정확히 `GET /`)이 실제 값과 달라 **이 환경에서는 발동하지 않는** 예외 룰.

- **파일**: `REQUEST-905-COMMON-EXCEPTIONS.conf` (line 17)
- **phase**: 1
- **action**: `pass`, `nolog` → chain → `ctl:ruleRemoveByTag=OWASP_CRS`, `ctl:auditEngine=Off`
- **로그**: 없음(nolog)
- **검증**: [`tests/905100.sh`](tests/905100.sh) — **SKIP(미발동)**

## 무슨 룰인가 (쉬운 설명)

- "예외(화이트리스트)" 룰이다. 공격을 막는 게 아니라, **로컬에서 오는 서버 헬스체크 요청을 봐주는** 룰이다.
- 조건이 맞으면 그 요청에 대해 **CRS를 잠시 끄고**(`ruleRemoveByTag`) **audit 로그도 끈다**(`auditEngine=Off`).

## 조건 → 동작

- **검사(2개 모두, chain)**:
  1. `REQUEST_LINE @streq GET /` → 요청 첫 줄이 **정확히 `GET /`**
  2. `REMOTE_ADDR @ipMatch 127.0.0.1,::1` → 접속 IP가 로컬
- **매칭되면**: `ctl:ruleRemoveByTag=OWASP_CRS` + `ctl:auditEngine=Off`

## 왜 발동하지 않나 (실측)

- 실제 `REQUEST_LINE` 은 **`GET / HTTP/1.1`** (HTTP 버전 포함)이다.
- `@streq` 는 **문자열 완전 일치**라서 `GET /` 와 `GET / HTTP/1.1` 은 **다르다** → 매칭 실패.
- 검증: `GET /` + `Host: 127.0.0.1`(원래 920350이 뜨는 조건) 요청 시
  920350이 **그대로 기록**됨 → CRS가 꺼지지 않았음(=예외 미적용).

> 참고: 같은 파일의 [905110](905110.md)은 조건에 HTTP 버전까지 포함(`HTTP/[12].[01]`)해 정상 발동한다.

## 흐름 / 관계

```
로컬 요청 (GET /)
  phase 1 · 905100 조건 검사
        ├─ (조건 충족 시) CRS 끄기 + audit 끄기
        └─ 실제로는 REQUEST_LINE='GET / HTTP/1.1' 이라 불일치 → 아무 일도 안 함
  → 이후 CRS 룰(예: 920350)이 정상 동작
```

## 배경: 왜 이런 룰이 기본 포함되어 있나

- **기원**: 2014년 Ryan Barnett이 `base_rules/REQUEST-01-COMMON-EXCEPTIONS.conf`에 추가한
  **Apache 전용 예외**(CHANGES: `exception for Apache SSL pinger (Request: GET /)`). 이후 id가 `901100 → 905100`으로 재번호.
- Apache `mod_ssl` 의 SSL pinger 요청 라인을 `GET /`(HTTP 버전 생략)로 가정해 작성했다.
- CRS는 Apache/nginx/IIS/Coraza **공용 룰셋**이라 커넥터별 변수 의미 차이를 안고 유지한다.
  → nginx+v3에서는 `REQUEST_LINE`이 항상 버전을 포함하므로 **사실상 no-op**.
- 그래도 기본 제공되는 이유:
  1. 다른 플랫폼(Apache)에서는 의도대로 동작할 수 있다.
  2. **안전** — 로컬(`127.0.0.1`,`::1`) 한정이라 보안 영향이 없다.
  3. **룰 ID 하위호환** — `SecRuleRemoveById 905100` 참조를 깨지 않는다.
  4. 오탐 완화 목적이라 제거할 실익이 적다.

## nginx에서 의도한 효과를 얻으려면

`REQUEST_LINE` 을 실제 값에 맞춰 직접 예외를 정의한다.

```
SecRule REQUEST_LINE "@beginsWith GET / HTTP/" \
    "id:1000100,phase:1,pass,nolog,chain"
    SecRule REMOTE_ADDR "@ipMatch 127.0.0.1,::1" \
        "t:none,ctl:ruleRemoveByTag=OWASP_CRS,ctl:auditEngine=Off"
```

## 검증

```
./tests/905100.sh
실제 REQUEST_LINE: GET / HTTP/1.1
SKIP 905100: 조건(@streq GET /) 불일치로 실환경 미발동 — 발동 검증 불가
```
