# 905110 — Apache internal dummy connection 예외

> **한 줄 요약**: 로컬에서 오는 Apache 내부 연결 확인 요청을 CRS가 오탐하지 않도록 **면제해 주는 룰**(정상 발동).

- **파일**: `REQUEST-905-COMMON-EXCEPTIONS.conf` (line 38)
- **phase**: 1
- **action**: `pass`, `nolog` → chain → `ctl:ruleRemoveByTag=OWASP_CRS`, `ctl:auditEngine=Off`
- **로그**: 없음(nolog)
- **검증**: [`tests/905110.sh`](tests/905110.sh) — **PASS**

## 무슨 룰인가 (쉬운 설명)

- "예외(화이트리스트)" 룰이다. 공격을 막는 게 아니라, **서버가 자기 자신에게 보내는 내부 요청을 봐주는** 룰이다.
- Apache는 재기동/graceful restart 등에서 `User-Agent`가 `(internal dummy connection)`으로 끝나는 요청을
  로컬로 보낸다. 이 요청에 CRS가 오탐하지 않게 한다.
- 조건이 맞으면 그 요청에 대해 **CRS를 끄고**(`ruleRemoveByTag`) **audit 로그도 끈다**(`auditEngine=Off`).

## 조건 → 동작

- **검사(3개 모두, chain)**:

| # | 대상 | 조건 |
|---|------|------|
| 1 | `REMOTE_ADDR` | `@ipMatch 127.0.0.1,::1` (로컬) |
| 2 | `REQUEST_HEADERS:User-Agent` | `@endsWith (internal dummy connection)` |
| 3 | `REQUEST_LINE` | `@rx ^(?:GET /\|OPTIONS \*) HTTP/[12]\.[01]$` |

- **매칭되면**: `ctl:ruleRemoveByTag=OWASP_CRS` + `ctl:auditEngine=Off`

## 흐름 / 관계

```
로컬 요청 (UA='... (internal dummy connection)', GET /)
  phase 1 · 905110 조건 3개 모두 충족
        → CRS 끄기 + audit 끄기
        → 이후 CRS 룰(예: 920350)이 동작하지 않음
```

- [905100](905100.md)과 달리 `REQUEST_LINE` 에 HTTP 버전까지 포함하므로 **정상 발동**한다.

## 배경: 왜 기본 포함되어 있나

- **대상**: Apache가 자기 자신에게 보내는 **internal dummy connection**.
- **기원**: 905100과 같은 계열(2014, Ryan Barnett)에서 시작, id `901110 → 905110` 재번호.
- **HTTP/2 확장 이력**: CHANGES에 `Extended 905100 and 905110 for HTTP/2.0` 기록 →
  현재 정규식이 `HTTP/1.0`, `HTTP/1.1`, `HTTP/2.0`, `HTTP/2.1` 을 포함.
- **공용 룰셋 / 로컬 한정 안전 / 룰 ID 하위호환** 으로 기본 제공된다(905100과 동일한 맥락).

## 검증 (920350을 "탐지 표식"으로 사용)

`Host: 127.0.0.1`(숫자 IP) 요청은 정상 시 CRS 룰 **920350** 을 발생시킨다.
예외가 적용되면 CRS가 꺼져서 920350이 사라지므로, 이걸로 확인한다.

| 시나리오 | UA | path | 920350 | audit | 결과 |
|----------|----|----|--------|-------|------|
| 트리거 | `Apache (internal dummy connection)` | `/` | **0** | **0** | PASS |
| 대조군1 | `Apache (internal dummy connection)` | `/x` | 1 | 1 | PASS |
| 대조군2 | `Apache` | `/` | 1 | 1 | PASS |

```
./tests/905110.sh
PASS 905110 트리거: CRS 제거(920350 사라짐)
PASS 905110 트리거: auditEngine=Off(audit 미기록)
PASS 905110 대조군1: REQUEST_LINE 불일치 → 예외 미적용(920350=1)
PASS 905110 대조군2: UA 불일치 → 예외 미적용(920350=1)
```
