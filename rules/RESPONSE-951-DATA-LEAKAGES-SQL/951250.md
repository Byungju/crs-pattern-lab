> **한 줄 요약**: 응답 본문 — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `RESPONSE-951-DATA-LEAKAGES-SQL.conf` (line 408)
- **phase**: 4
- **검사 대상(변수)**: `RESPONSE_BODY` → 응답 본문
- **조건(연산자)**: `@rx (?i)Warning.*(?:sqlite_|SQLite3::)|S(?:QLite(?:/JDBCDriver|\.Exception)|ystem\.Data\.SQLite\.SQLiteException)`

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 응답 본문 (`RESPONSE_BODY`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: 없음 (`t:none`)
