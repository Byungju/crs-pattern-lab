## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 응답 본문 (`RESPONSE_BODY`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: 없음 (`t:none`)

- **정본**: `regex-assembly/951230.ra` (사람이 읽는 조립 파일)
- **구조**: 대소문자 무시(`(?i)`)
- **패턴 조각 15개** (조각 중 하나라도 매칭되면 탐지):

    3. `mysql_fetch_array\(\)`
    4. `on MySQL result index`
    5. `You have an error in your SQL syntax;`
    6. `You have an error in your SQL syntax near`
    7. `MySQL server version for the right syntax to use`
    8. `\[MySQL\]\[ODBC`

    10. `Table '[^']+' doesn't exist`
    11. `Warning.{1,10}mysql_(?:[a-z_()]{1,26})?`
