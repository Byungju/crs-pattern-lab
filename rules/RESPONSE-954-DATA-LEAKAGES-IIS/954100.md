# 954100 — Disclosure of IIS install location

> **한 줄 요약**: 응답 본문 — 정규식 패턴 탐지 [오류(ERROR)]

- **파일**: `RESPONSE-954-DATA-LEAKAGES-IIS.conf` (line 34)
- **phase**: 4
- **검사 대상(변수)**: `RESPONSE_BODY` → 응답 본문
- **조건(연산자)**: `@rx (?i)[a-z]:[\x5c/]inetpub\b`
- **심각도(severity)**: 오류(ERROR) → 점수 4

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 응답 본문 (`RESPONSE_BODY`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 오류(ERROR) 등급으로 **점수 4** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
