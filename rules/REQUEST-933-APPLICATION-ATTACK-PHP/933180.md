# 933180 — PHP Injection Attack: Variable Function Call Found

> **한 줄 요약**: 여러 입력값(파라미터·쿠키·헤더·본문 등) — 정규식 패턴 탐지 [치명(CRITICAL)]

- **파일**: `REQUEST-933-APPLICATION-ATTACK-PHP.conf` (line 504)
- **phase**: 2
- **검사 대상(변수)**: `REQUEST_COOKIES|REQUEST_COOKIES_NAMES|REQUEST_FILENAME|ARGS_NAMES|ARGS|XML:/*|XML://@*` → 여러 입력값(파라미터·쿠키·헤더·본문 등)
- **조건(연산자)**: `@rx \$+(?:[A-Z_a-z\x7f-\x{ff}][0-9A-Z_a-z\x7f-\x{ff}]*|[\s\x0b]*\{[^\}]+\})(?:[\s\x0b]|\[(?:[^\[\]]|\[[^\]]+\])+\]|\{[^\}]+\}|/(?:\*[^\*]*\*+(?:[^\*/][^\*]*\*+)*/|/[^\n\r]*[\n\r])|#[^\n\r]*[\n\r])*\(.*\)`
- **심각도(severity)**: 치명(CRITICAL) → 점수 5
- **paranoia level**: 1
- **검증**: [`tests/933180.sh`](tests/933180.sh)

## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`REQUEST_COOKIES|REQUEST_COOKIES_NAMES|REQUEST_FILENAME|ARGS_NAMES|ARGS|XML:/*|XML://@*`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 분류 / 근거 (OWASP·CWE·CAPEC)

- **공격 분류**: PHP Code Injection
- **CWE**: CWE-94
- **OWASP Top 10 2025**: A05:2025 – Injection
- **CAPEC (CRS 태그)**: `capec/1000/152/242`
- **분류·근거 문서**: [공격 분류 개요](../../modsecurity/attack-classes.md)

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: 없음 (`t:none`)

- **정본**: `regex-assembly/933180.ra` (사람이 읽는 조립 파일)
- **구조**: 접두 고정 `\$+`
- **정의(매크로)**: `php-id-start` = `[a-zA-Z_\x7f-\xff]`, `php-id-chars` = `[a-zA-Z0-9_\x7f-\xff]`
- **패턴 조각 10개** (조각 중 하나라도 매칭되면 탐지):
    1. `\s`
    2. `\[(?:[^[\]]|\[[^\]]+\])+\]`
    3. `\{[^}]+\}`
    4. `/\*[^*]*\*+(?:[^/*][^*]*\*+)*/`
    5. `//[^\n\r]*[\n\r]`
    6. `#[^\n\r]*[\n\r]`
    7. `*`
    8. `{{php-id-start}}{{php-id-chars}}*`
    9. `\s*\{[^}]+\}`
    10. `\(.*\)`
