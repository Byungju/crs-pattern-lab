## 무슨 룰인가 (쉬운 설명)

- **무엇을 보나**: 여러 입력값(파라미터·쿠키·헤더·본문 등) (`REQUEST_COOKIES|REQUEST_COOKIES_NAMES|REQUEST_FILENAME|ARGS_NAMES|ARGS|XML:/*|XML://@*`)
- **어떻게 판단하나**: 정규식 패턴에 매칭되면 탐지
- **매칭되면**: 치명(CRITICAL) 등급으로 **점수 5** 를 누적한다 (실제 403 차단은 `949110`(요청) / `959110`(응답)이 담당).

## 정규식 / 패턴 해설

- **연산자 의미**: 정규식 패턴에 매칭되면 탐지
- **변환(transform)**: `t:urlDecodeUni`, `t:replaceComments`, `t:removeWhitespace` (비교 전에 적용)

- **정본**: `regex-assembly/933210.ra` (사람이 읽는 조립 파일)
- **구조**: 접미 고정 `;`
- **정의(매크로)**: `single_or_double_quotes` = `['"]`, `string_in_round_brackets` = `\(.+\)`
- **패턴 조각 7개** (조각 중 하나라도 매칭되면 탐지):
    1. `\(.+\)\(.+\)`
    2. `\(.+\)['"][a-zA-Z-_0-9]+['"]\(.+\)`
    3. `\[\d+\]\(.+\)`
    4. `\{\d+\}\(.+\)`
    5. `\$[^(\),.;\x5c/]+\(.+\)`
    6. `['"][a-zA-Z0-9-_\x5c]+['"]\(.+\)`
    7. `\([^\)]*string[^\)]*\)[a-zA-Z-_0-9\"'.{}\[\]\s]+\([^\)]*\)`
